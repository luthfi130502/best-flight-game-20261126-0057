SKYLINE COURIER (Merpati Express) — an original bush-pilot courier flight game built for the [make.fun best flight game bounty](https://make.fun/bounty/best-flight-game-20261126-0057). A hand-written software-3D chase-view flight game in plain Canvas 2D: no libraries, no assets, no network. Fly three sorties over two procedural islands — ring runs, island hops, and a storm courier leg — with fuel, stall, and judged landings.

Play: open `game/index.html` in a desktop browser (keyboard + mouse). `main.ts` hands the game in to the make.fun grader.
